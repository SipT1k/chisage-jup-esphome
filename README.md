# Chisage JUP ESPHome Integration

ESPHome-based RS485/Modbus integration for Chisage JUP inverters with Home Assistant, supporting real-time monitoring and inverter control.

## Overview

This project aims to connect Chisage JUP inverters to Home Assistant using an ESP32 and an RS485 interface.

## Features

- Read inverter data through RS485/Modbus.
- Expose inverter sensors in Home Assistant.
- Support inverter control through ESPHome.
- Monitor inverter faults and warnings.
- Explore Time of Use (TOU) functionality.

## Hardware

- Chisage JUP inverter
- ESP32 development board
- RS485 transceiver compatible with the inverter's communication interface
- Home Assistant
- ESPHome

## Project status

This project is under development. Supported features, hardware compatibility, and setup instructions will be documented as they are tested.

## Safety and security

Never publish Wi-Fi credentials, API encryption keys, OTA passwords, or other secrets. Keep private values in your ESPHome `secrets.yaml` file.
